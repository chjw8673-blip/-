# 레몬마켓 — QR 참가형 실시간 게임

참가자는 Node.js 설치가 필요 없습니다. **진행자도 Node.js 설치 없이** GitHub와 Render에서 온라인 배포하면, QR코드를 통해 50명 이상이 각자 휴대폰 브라우저로 플레이할 수 있습니다.

## 배포 단계 (진행자 1회 설정)
1. GitHub에서 새 저장소(repository)를 만들고 이 압축파일 **내부의** `server.js`, `package.json`, `render.yaml`, `public/index.html`을 원래 폴더 구조대로 업로드합니다. `.gitignore`도 올리면 좋습니다.
2. Render.com에 로그인하여 **New → Blueprint**를 선택하고 GitHub 저장소를 연결합니다. 저장소 루트의 `render.yaml`을 읽어 웹 서비스를 생성합니다.
3. `ADMIN_KEY`를 요구하면 **강력한 진행자 비밀번호**를 입력합니다. 공유하지 마세요.
4. 배포 완료 후 제공되는 `https://...onrender.com` 주소를 진행자 브라우저에서 엽니다. **진행자 로그인**에 위 비밀번호를 입력합니다.
5. 진행자 대시보드에 나타나는 QR코드를 강의실 스크린에 띄웁니다. 학생들은 QR로 접속해 닉네임만 입력하면 됩니다. 참가 코드는 QR에서 자동 입력됩니다.
6. 등록 인원이 짝수인 것을 확인하고 1라운드를 시작합니다. 50명은 25쌍으로 자동 배정됩니다.

## 5라운드 흐름
- 매 라운드 참가자 절반씩 판매자/구매자로 무작위 배정. 판매자에게 차량의 H/L 품질만 비밀 통보.
- 구매자에게는 인증된 차량의 품질만 표시합니다. 인증률은 0%,25%,50%,75%,100%입니다.
- 구매자: 6점 제시 / 14점 제시 / 포기 → 판매자: 수락 / 거절.
- 결과: 거래 성사 수, 좋은 차·결함 차 판매 수, 총잉여, 누적 추이. 진행자는 CSV 다운로드 가능.
- 제시가격이 0인 경우 판매자에게 구매 포기를 통보합니다.

## 수업 운영 전 반드시 확인
- **Render 무료 웹서비스는 15분 비활성 시 휴면**합니다. 강의 시작 전에 접속해 동작을 확인하세요.
- **무료 호스팅의 로컬 파일은 영구 저장되지 않습니다.** 앱은 `game-data.json`에 상태를 저장하지만, 서버 재배포/재시작 시 데이터가 사라질 수 있습니다. 실제 평가에 사용한다면 유료 영속 디스크 또는 외부 DB를 연결하세요.
- 무료 환경의 50명 동시접속 성능은 보장되지 않습니다. 수업 전에 여러 기기에서 예행연습하고 결과 CSV를 즉시 내려받으세요.
- QR 생성 이미지는 `api.qrserver.com` 서비스를 사용합니다(참가 URL만 전송). 네트워크가 이를 차단하면 진행자가 **참가 링크 복사**로 주소를 공유하면 됩니다.
- 참가자 화면은 별도 설치 없이 웹에서 작동합니다. 강의실에서 QR로 접속하는 학생은 GitHub나 Render 계정이 필요하지 않습니다.

게임 방식은 순차 제안/수락 형태로, 판매자가 가격을 먼저 게시하는 이전 버전과 다릅니다. 실험은 품질 H/L과 인증 효과를 관찰하기 위한 수업용 간소화 모형입니다.
